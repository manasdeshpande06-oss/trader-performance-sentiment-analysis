
# Trader Performance vs Market Sentiment Analysis

## Objective

This project analyzes the relationship between Bitcoin market sentiment (Fear & Greed Index) and trader behavior on Hyperliquid. The objective is to identify patterns in trader profitability, trading activity, position sizing, and directional bias under different market sentiment conditions.

## Project Structure

* `analysis.ipynb` – Complete data cleaning, analysis, and visualization notebook
* `charts/` – Output charts generated from the analysis
* `summary.md` – Methodology, insights, and strategy recommendations

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Setup

Install required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

## How to Run

1. Clone the repository
2. Open Jupyter Notebook
3. Run `trader.ipynb`
4. Generated charts will be available in the charts folder

## Dataset

* Bitcoin Fear & Greed Index Dataset
* Hyperliquid Historical Trader Dataset
